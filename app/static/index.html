How answers are produced

Checking AI provider…

Every answer is grounded in approved official content or live data, with the source and last-updated date shown. Emergencies bypass the AI model and return safety instructions immediately.

Pipeline

  1. Language detection (script-based) – Bhashini for other Indian languages
  2. Intent classification (TF-IDF + logistic regression) with emergency override
  3. Hybrid retrieval over the bilingual knowledge base
  4. Live enrichment: crowd forecast & route-risk services
  5. Grounded answer (LLM if configured, else extractive) + guardrails
